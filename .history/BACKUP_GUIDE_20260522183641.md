## 🚀 Quick Start

### 1. Installation

```bash
cd salesflow-backend
npm install
```

New packages installed:
- `archiver` - ZIP compression
- `node-cron` - Task scheduling  
- `uuid` - Unique backup IDs

### 2. Environment Configuration

Add to `.env`:

```env
# Backup Scheduling (cron format)
BACKUP_SCHEDULE="0 2 * * *"        # Daily at 2:00 AM
BACKUP_CLEANUP="0 3 * * 0"         # Weekly Sunday at 3:00 AM
BACKUP_KEEP_COUNT=5                # Keep last 5 backups

# MongoDB URI (already exists)
MONGODB_URI=mongodb+srv://...
```

### 3. Start the Server

```bash
npm run dev
```

✅ Backup scheduler will automatically start!

## 💾 Using the Backup System

### Manual Backups (Command Line)

```bash
# Create a full backup right now
npm run backup

# List all available backups
npm run backup list

# Clean old backups (keep last 5)
npm run backup clean 5

# Export a backup as ZIP
npm run backup export backup-2026-05-22-abc12345

# Show help
npm run backup help
```

### Manual Backups (API)

**Create backup:**
```bash
POST http://localhost:3000/api/v1/backups/manual
Authorization: Bearer <token>
```

**List all backups:**
```bash
GET http://localhost:3000/api/v1/backups
Authorization: Bearer <token>
```

**Get specific backup:**
```bash
GET http://localhost:3000/api/v1/backups/<backup-name>
Authorization: Bearer <token>
```

**Download backup:**
```bash
GET http://localhost:3000/api/v1/backups/<backup-name>/download
Authorization: Bearer <token>
```

**Cleanup old backups:**
```bash
DELETE http://localhost:3000/api/v1/backups/cleanup
Authorization: Bearer <token>
Content-Type: application/json

{
  "keepCount": 5
}
```

## 🎨 Creative Backup Suggestions

### 1. **Version Control Backups** 📈
Keep backups organized by date and purpose:

```
backups/
├── backup-2026-05-22-daily.zip       # Regular daily
├── backup-2026-05-20-weekly.zip      # Sunday backup
├── backup-2026-05-01-monthly.zip     # First of month
└── backup-2026-01-01-quarterly.zip   # End of quarter
```

**Implementation:**
```javascript
// Tag backups with purpose
const backupType = new Date().getDate() === 1 ? 'monthly' : 'daily';
const backupName = `backup-${date}-${backupType}`;
```

### 2. **Cloud Backup Integration** ☁️

Store backups to AWS S3, Google Cloud, or Azure:

```bash
npm install aws-sdk
```

**Add to backup service:**
```javascript
async function uploadToS3(backupPath) {
  const s3 = new AWS.S3();
  const fileStream = fs.createReadStream(backupPath);
  
  await s3.upload({
    Bucket: process.env.AWS_BACKUP_BUCKET,
    Key: `backups/${path.basename(backupPath)}`,
    Body: fileStream
  }).promise();
}
```

**Environment variables:**
```env
AWS_ACCESS_KEY_ID=your-key
AWS_SECRET_ACCESS_KEY=your-secret
AWS_BACKUP_BUCKET=fairdirection-backups
```

### 3. **Incremental Backups** 🔄
Only backup changed data (faster, less storage):

```javascript
async function incrementalBackup() {
  const lastBackup = await getLastBackupDate();
  const changesSince = new Date(lastBackup);
  
  // Query only modified documents
  const changes = await db.collection('sales').find({
    updatedAt: { $gte: changesSince }
  }).toArray();
  
  return backupData(changes, 'incremental');
}
```

### 5. **Backup Dashboard Widget** 📊

Frontend component to monitor backups:

```angular
// backup-status.component.ts
export class BackupStatusComponent implements OnInit {
  backups: Backup[] = [];
  lastBackup: Backup | null = null;
  
  ngOnInit() {
    this.loadBackups();
    setInterval(() => this.loadBackups(), 3600000); // Check hourly
  }
  
  async loadBackups() {
    this.backups = await this.backupService.getBackups();
    this.lastBackup = this.backups[0];
  }
  
  async downloadBackup(backup: Backup) {
    window.open(`/api/v1/backups/${backup.name}/download`);
  }
  
  getTimeAgo(date: string): string {
    const hours = Math.floor((Date.now() - new Date(date).getTime()) / 3600000);
    return `${hours} hours ago`;
  }
}
```

### 6. **Backup Integrity Verification** ✔️

Verify backup completeness:

```javascript
async function verifyBackup(backupName) {
  console.log(`🔍 Verifying backup: ${backupName}`);
  
  const manifest = await getBackupManifest(backupName);
  const issues = [];
  
  // Check database files
  for (const [collection, stats] of Object.entries(manifest.database.collections)) {
    const filePath = path.join(manifest.database.path, `${collection}.json`);
    
    if (!fs.existsSync(filePath)) {
      issues.push(`Missing collection export: ${collection}`);
    } else {
      const size = fs.statSync(filePath).size;
      if (size === 0) issues.push(`Empty collection file: ${collection}`);
    }
  }
  
  // Check file count
  const fileCount = fs.readdirSync(manifest.files.path).length;
  if (fileCount === 0 && manifest.files.size !== '0 bytes') {
    issues.push('Files directory appears empty but manifest shows files');
  }
  
  if (issues.length === 0) {
    console.log('✅ Backup is valid and complete');
    return { valid: true };
  } else {
    console.log('⚠️ Backup issues found:', issues);
    return { valid: false, issues };
  }
}
```

### 7. **One-Click Restoration Interface** 🔄

Simple restoration:

```angular
// restore-backup.component.ts
async restoreFromBackup(backup: Backup) {
  const confirmed = await this.dialog.confirm(
    'Restore from backup?',
    `This will restore data from ${backup.date}. Current data will be overwritten.`
  );
  
  if (!confirmed) return;
  
  this.loading = true;
  try {
    await this.backupService.restoreBackup(backup.name);
    this.notificationService.success('✅ Restoration complete!');
    window.location.reload();
  } catch (error) {
    this.notificationService.error('❌ Restoration failed');
  }
  this.loading = false;
}
```

### 10. **Backup Health Monitoring** 🏥

Alert if backups fail:

```javascript
async function monitorBackupHealth() {
  const backups = await listBackups();
  const lastBackup = backups[0];
  
  if (!lastBackup) {
    sendAlert('❌ NO BACKUPS FOUND - System is vulnerable!');
    return;
  }
  
  const hoursSinceBackup = (Date.now() - new Date(lastBackup.timestamp)) / 3600000;
  
  if (hoursSinceBackup > 24) {
    sendAlert(`⚠️ Last backup was ${Math.floor(hoursSinceBackup)} hours ago`);
  }
  
  if (lastBackup.status !== 'success') {
    sendAlert(`❌ Last backup failed: ${lastBackup.status}`);
  }
}
```

## 🛠️ Cron Schedule Patterns

Use at `BACKUP_SCHEDULE` in `.env`:

```
"0 2 * * *"        → Every day at 2:00 AM
"0 2 * * 0"        → Every Sunday at 2:00 AM
"0 0 1 * *"        → Every month 1st at midnight
"0 0 1 1 *"        → Every quarter (Jan 1, Apr 1, etc.)
"0 */6 * * *"      → Every 6 hours
"0 1,13 * * *"     → 1:00 AM and 1:00 PM daily
"*/30 * * * *"     → Every 30 minutes
"15 10 15 * *"     → 10:15 AM on 15th of month
```

Visit [crontab.guru](https://crontab.guru/) for interactive patterns.

### If Data is Lost:

1. **Stop the application** immediately
2. **Locate latest backup**: `npm run backup list`
3. **Restore from backup**: See restoration script (to be created)
4. **Verify data integrity** before restarting
5. **Restart application**

## 📞 Support & Troubleshooting

**Q: Backups not running?**
- Check `.env` configuration
- Verify MongoDB connection: `npm run backup list`
- Check `npm run dev` console for error messages

**Q: Backup directory is too large?**
- Run cleanup: `npm run backup clean 3` (keep last 3)
- Enable cloud backups to move old files
- Consider incremental backups

**Q: Want to restore from backup?**
- Contact development team for restoration script
- Provide backup ID from manifest
